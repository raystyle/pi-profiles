# 漏洞六族判型总纲

来源:蒸馏自 prs_c2coe knowledge/business-logic-vulnerability/vuln-families/(六族页,
各带 campaign 实录映射);判型矩阵与共性律全量收录,实录编号与工具反查不迁(那是
来源仓的索引)。用法:开题先判族 -> 子型判型特征定位 -> 手法方向选件。与本仓
records 的族链接([[race-conditions-family]] [[h2-smuggling-family]] 等)互补:那些是
本仓实录沉淀,本页是跨题型分型总纲。

## 访问控制族(越权与 API 面)

共性成因:鉴权点与业务点分离,数据可达而校验缺位。

| 子型 | 判型特征 | 手法方向 |
|---|---|---|
| 水平越权 | 对象标识可改 | 改 id/accountId;不可预测 ID 先取再改 |
| 垂直越权(角色位) | 角色字段进可写面 | profile 或参数改 role |
| 垂直越权(方法或头错配) | 鉴权按方法或 Referer | POST 改 GET 重放;Referer 补头 |
| 未认证面 | 管理接口无访问控制 | 直访未防护路径;robots 与 JS 泄露路径 |
| 多步漏校验 | 流程末步无鉴权 | 跳中间步直发末步 |
| 数据泄露 | 响应或重定向带敏感位 | 跟随重定向读响应体、hidden 回显 |
| URL 级控制 | 路径即权限 | 绝对路径、X-Original-URL 覆写 |
| API 面 | 文档或端点暴露 | openapi 枚举、参数污染、mass assignment、隐藏方法 |

共性律:鉴权决策点后置或缺位;客户端导航即权限幻觉(菜单不显示不等于服务端拒绝);
多步流程只验首步。

## 认证族(认证与会话)

共性成因:认证状态的生成、传递、复核三段中任一段可被跳过、伪造或观测。

| 子型 | 判型特征 | 手法方向 |
|---|---|---|
| 2FA 跳步 | 登录态未绑第二步 | 直跳登录后页面 |
| 2FA 逻辑破坏 | verify 标志可操纵 | 改 session 位、重置链 |
| 2FA 码空间小 | 短码无尝试限制 | 共用登录会话全窗口扫码 |
| OAuth 绕过 | 客户端信令牌面身份参数 | implicit 改 username 即登他户;redirect_uri 前后缀误信;绑定流无 state;白名单追加路径链式外携;动态注册 logoUri SSRF |
| 用户枚举(响应) | 文案或状态差 | 三差分逐一标定 |
| 用户枚举(时延) | 有效名认证注入人工延迟 | 超长口令放大时延差分 |
| 重置逻辑破坏 | token 与账号不绑定 | 改 username 重放 token |
| 重置投毒 | 链接外部地址取自转发头 | 携攻击域转发头截获令牌 |
| 爆破面错置 | 非登录端点做校验 | 改密端点、cookie 通道爆破 |
| 封锁可绕过 | 计数按请求或可控头 | JSON 数组单请求;转发头轮换 |
| 离线破解 | 凭据可逆形 | 偷 stay-logged-in cookie 离线查表 |
| JWT 伪造面 | 三段 eyJ 令牌 | 六型:不验签/none/弱密钥/jwk/jku/kid |

共性律:状态绑定缺失(登录态与二因子态、重置令牌与账号互不绑定);侧信道泄露存在性
(响应文案、认证时延、锁定行为都是枚举 oracle);防护计数粒度错位(按请求数或可控头
计数,与认证尝试粒度不一致)。

## 业务逻辑族

共性成因:服务端把本应服务端裁决的量(价格、数量、顺序、余额)交给客户端或交给
可推演的弱规则。

| 子型 | 判型特征 | 手法方向 |
|---|---|---|
| 高层逻辑 | 价格或数量在客户端定 | 篡改后重放 |
| 客户端信任 | 前端算价或传总价 | 绕过前端直接提交 |
| 工作流跳步 | 状态机步骤可乱序 | 缺步、乱序重放 |
| 低层数值 | 整数溢出或负数 | 边界值注入 |
| 不一致控制 | 同数据两面校验差 | 双面差分 |
| 规则可推 | 优惠码或竞猜有规律 | 模式推断(局部一致即弱) |
| 去重单步记忆 | 用码去重只记上一次 | 两码交替叠折 |
| 异常输入 | 超长截断进另上下文 | 截断边界探测 |
| 财务闭环 | 循环可套利 | 买退券环 |
| 加密预言机 | 双面预言机可锻造密文 | 评论面加解密双预言机割块伪造凭据 |
| 竞态限溢 | 校验与写库间竞态窗 | 末字节同步单包突重复用一次性资源;确认链接单包重放绕限速 |

共性律:信任锚漂移(同一数据在注册面/展示面/结算面校验强度不一致);状态机无序推进
(每步只信到达标记不验前置);数值域未闭合;规则局部一致即弱。

## 注入族(注入与逃逸)

共性成因:数据与代码的边界失效,输入被当作语法的一部分执行。

| 子型 | 刹型特征 | 手法方向 |
|---|---|---|
| OS 命令注入 | 回显或分隔符面 | 分隔符枚举、时延、带外外传三梯 |
| XSS 上下文逃逸 | 输入落点上下文 | 标签/属性/编码逐层逃逸;自定义标签配 onfocus 加 hash 聚焦;罕见事件 onresize 配 iframe 改宽引爆;DOM cookie 染毒跨页引爆 |
| 路径遍历 | 文件参数 | 过滤消解五型:绝对路径/双解码/剥叠/空字节/前缀 |
| 上传攻击面 | 文件入口 | 类型/黑名单/竞态/路径/多态;黑名单混淆绕过(编码空字节加尾缀);多态穿透(BMP 头加脚本体过内容校验) |
| SQL 注入(基础) | WHERE 拼接 | 恒真短路、注释截除与方言差 |
| SQL 注入(UNION) | 回显列 | 列数、文本位、其他表三步 |
| SQL 注入(指纹) | 方言差 | 版本与列举双方言模板 |
| SQL 注入(盲注) | 无回显 | 五信道:条件响应/可见错误/时延/条件错误/出网外呼 |
| SQL 注入(WAF) | 关键词过滤 | XML 实体编码绕过 |
| NoSQL(运算符) | JSON 面、运算符 | 恒真检测、不等加正则绕认证、键枚举提取 |
| NoSQL(拼接) | 字符串拼接 | 布尔条件加尾缀闭合逐位提取 |
| SSTI | 模板渲染用户输入 | 断串定引擎、乘法探测、沙箱内建禁令旁路(Object 方法链) |
| 反序列化 | 会话 cookie 携序列化对象 | 改对象提权、改数据类型、应用功能滥用、gadget 链 |
| XXE | XML 解析器外联 | 文件读、URL 代取、XInclude、盲出网、参数实体外传、图片上传面 |

共性律:判型先于利用(断串或乘法探针定引擎与语法语境再选逃逸形);无回显换信道
(错误页/时延/出网三梯任一作 oracle);编码对抗是横切面。

## 请求伪造族(SSRF 与头信任)

共性成因:服务端把客户端输入当作路由、寻址或信任判定的权威来源。

| 子型 | 判型特征 | 手法方向 |
|---|---|---|
| SSRF(全读型) | 回取参数回显响应体 | 环回与内网代取,响应回注即证据 |
| SSRF(内网后端) | 管理面在内网随机主机 | 段扫定位,代取通道操作 |
| SSRF(过滤形) | 黑白名单过滤 | 主机短形、路径双编码、白名单双语境分裂、重定向伪装 |
| SSRF(盲面) | 无回显 | **放行域子域命中判解**(见 [[prs-c2coe-oob-collaborator-verdict]]) |
| Host 头信任 | 链接或路由取 Host 族 | 精确 Host、转发主机头注入 |
| 开放重定向 | 跳转参数任意目标 | 相对伪装携绝对目标 |
| CSRF | 状态变更防护形异 | 表单伪造/跨域携带/CRLF 种 cookie/方法覆写/Referer 子串误信/SameSite Lax 配 GET 导航等十型 |
| 点击劫持 | 帧防护全无 | iframe 近透明叠层,受害者本尊点击直发 |
| WebSocket 消息操纵 | 帧通道免客户端编码 | WS 帧直发载荷,接收方渲染即 XSS;握手操纵跨站劫持 |
| CORS 配置错 | 反射任意源/null 源受信 | 源头注入与凭据携带 |

共性律:校验语境与请求语境分离(过滤在解析前做);网络位置当鉴权(环回或内网可达
即放行);头信任链(转发头族被中间件当权威)。

## 泄露族(信息泄露)

共性成因:生产面携带了开发期资产或未捕获异常细节。

| 子型 | 判型特征 | 手法方向 |
|---|---|---|
| 错误回显 | 类型混淆触发堆栈 | 数字位灌非整数,栈尾取框架版本 |
| Web 缓存欺骗 | 缓存与源站路径映射差 | 路径映射(regex 后缀映会话页配静态扩展名)、归一化双面、界符差 |
| 方法回显 | TRACE 类自回显 | 回显读内部鉴权头,伪头复访 |
| 备份件 | 目录索引列残留件 | robots 线索直读,连接串取口令 |
| 版本控制历史 | .git 可直读 | 引用日志定位,逐对象解压还原 |
| 调试页 | 诊断件入生产 | 注释线索直访,环境表取密钥 |
| 响应扫 | 回执带密钥或内网信息 | 模式清单被动扫 |

共性律:泄露即凭据;位置线索链(robots 禁扫段、页面注释、目录索引互相指路);
删除不等于抹除(版本控制历史与备份件保留被删资产)。
